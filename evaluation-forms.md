# E.M. Cayetano Store Management System Evaluation Forms

## Revised Software Description

The E.M. Cayetano Store Management System is a web-based system developed for E.M. Cayetano Trading to manage store inventory, sales, purchases, suppliers, users, archives, alerts, reports, audit records, and maintenance records in one platform. It allows authorized users to search products, monitor stock levels, record stock-in and stock-out transactions, process sales, encode supplier purchases, generate reports, manage archived records, and receive low-stock or system alerts. The system also supports role-based access, account approval, two-factor authentication, backup and restore, audit trails, and data checking to help improve record accuracy, reduce manual work, and support store monitoring and decision-making.

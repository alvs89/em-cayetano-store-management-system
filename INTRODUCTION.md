# Welcome to E.M. Cayetano Store Management System

## What This System Is About

The **E.M. Cayetano Store Management System** is a comprehensive web-based platform designed to streamline inventory and store operations for E.M. Cayetano Trading. Built as a modern, responsive application, it centralizes all critical business operations into one unified dashboard.

## Core Purpose

This system enables the store to:

- **Monitor Real-Time Inventory** - Track stock levels across all branches instantly
- **Manage Stock Movements** - Record and process stock-in and stock-out transactions efficiently
- **Track Alerts & Notifications** - Stay informed of low stock levels and critical system events
- **Generate Comprehensive Reports** - Export detailed inventory and sales reports in PDF format
- **Maintain Audit Trails** - Keep complete records of all user actions for compliance and accountability
- **Manage Users & Access** - Administer employee accounts and control role-based permissions
- **Archive Historical Data** - Organize and preserve inactive records for long-term reference

## Key Features

✅ **Secure Authentication** - Login with two-factor verification for account security
✅ **User-Friendly Dashboard** - Quick access to inventory summaries, recent activity, and alerts
✅ **Product Search** - Fast and intuitive product lookup across the database
✅ **Mobile-Responsive Design** - Seamless experience on desktop, tablet, and mobile devices
✅ **Real-Time Data Sync** - Instant updates across all connected devices
✅ **Admin Tools** - Maintenance utilities and system administration features
✅ **Comprehensive Logging** - Full audit trail of all transactions and user activities

## Who Uses This System

- **Store Employees** - View inventory, search products, and process stock movements
- **Store Managers** - Access reports, manage inventory, and monitor operations
- **System Administrators** - Manage user accounts, perform maintenance, and oversee system health

## Getting Started

1. **Login** with your credentials
2. **Explore the Dashboard** to see your inventory summary
3. **Navigate to Modules** for specific tasks (Inventory, Reports, Alerts, etc.)
4. **Generate Reports** to analyze trends and stock levels
5. **Contact Support** if you need assistance
